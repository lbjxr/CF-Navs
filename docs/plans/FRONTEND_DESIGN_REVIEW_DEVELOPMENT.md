## 3. 逐项实现与验收契约

### PROB-40：登录弹窗原生模态与开关同步

**原因与入口**：`src/components/LoginModal.svelte` 的 `LoginModal` 使用自制遮罩和 ARIA 模态声明，却没有初始焦点和背景焦点隔离。匿名 Chrome 观察到打开后焦点在背景，Tab 继续经过背景控件，Esc 不关闭。

**职责与接口**：

- `App` 继续拥有 `loginModalOpen` 和由公开模式/认证状态推导的 `canSeeHome`。
- `appAuthController` 继续负责 `openLogin`、`closeLogin`、`login` 与 `forgotPassword`；私有站点的关闭请求不能离开登录门禁。
- `LoginModal` 只拥有用户名、密码与原生节点引用。通过 `open`、`loading`、`error`、取消资格和提交/取消/找回回调通信。
- `showModal()` / `close()` 与原生事件处理属于登录组件的 DOM 副作用；不得增加第二套全局模态状态或叠加手写 Tab 陷阱。

**实现范围**：登录组件、App 的必要属性接线、组件接线测试和登录浏览器回归脚本。保留当前表单 trim、密码原值、重新打开重置、保存中禁用和白色外观。不迁移其他弹窗，不改鉴权 API。

**验收**：

1. 打开后焦点进入登录区域；Tab/Shift+Tab 不访问背景；公开站点 Esc 和取消正常关闭。
2. 私有站点、登录请求进行中及重复关闭请求不能绕过资格；关闭被拒时有可读说明。`closedby` 属渐进增强，门禁不能只依赖该属性。
3. 父状态关闭、登录成功与找回密码释放原生模态，迟到的原生 close 事件不能触发旧取消或重开。
4. 关闭返回可见的唤起位置；通过实际首页设置菜单测试，不能只使用一直可见的测试按钮。
5. 重新打开清空表单；错误/加载属性变化保留当前输入；登录失败可重试。
6. 320/390px 窄屏和短高度中字段、错误与操作区可达；避免切换 body overflow 导致布局跳动。

**验证**：L0 + L2。jsdom 验证 props 与原生 API/回调接线，真实浏览器验证原生焦点、滚动和视口行为；新增回归须有一次精确反向对照。生产、Safari、真实软键盘和实际读屏范围单独说明。

**落地取舍与验证依据（2026-11-24）**：保留常驻原生 dialog 节点，使父级先 `close()` 释放模态和原生焦点，再等待后续开关。原生 close 事件排队执行，组件记录父关闭事件的数量并在原生事件中消耗，防止旧事件取消新会话；这项局部状态有混合队列行为测试及破坏保护后重复通知的反向证据。`HomeFloatingActions.handleOpenLogin` 复用已有 `closeMenu(true)`，在异步加载前选定持续可见的 invoker，关闭后由浏览器归还焦点。组件不叠加手写 Tab 限制、背景 inert 或关闭后手动回焦点，也不通过 root overflow 隐藏改变滚动条。

`tests/unit/loginModalBehavior.test.ts` 与 `tests/helpers/nativeDialog.ts` 仅模拟原生 API 和延迟事件；真实原生行为由 `scripts/login-modal-regression.mjs` 加载实际构建，以合成请求执行 10 组 / 35 项断言验证。L0 的全量 243 文件 / 2,975 测试、lint、类型、构建、首屏体积门通过，专项与独立审查的局部结论不推广为生产或其他浏览器验收。原始 JSON 与截图留在仓库外，公开实现及验证边界见 [CHANGELOG](../../CHANGELOG.md)。

### PROB-41：后台设置未保存草稿保护

**原因与入口**：`SettingsPanel` 拥有 `form`、`initialForm` 与 `isDirty`，`AdminTabContent` 按栏目条件挂载；`Admin.handleSelectTab` 立即切栏目，使草稿随组件卸载丢失。

**职责**：草稿保持单一所有者。优先由 `SettingsPanel` 提供小的脏状态/保存结果接口，`Admin` 编排离开决策；若提升草稿所有权，只有一个模块可修改它。持久化仍由现有 `appSettingsController` 负责。

**实现范围**：`SettingsPanel`、`Admin`、`AdminTabContent` 以及必要的离开请求接线。不在导航时自动写远端，不把密码或草稿写入长期浏览器存储。

**验收**：改设置后切栏目/回首页提供保存、放弃、继续编辑；保存失败留在原处并保留草稿，成功后清除脏状态；刷新提示只在确有修改时存在并正确清理监听；退出/认证失效的清理不能复活旧草稿。覆盖取消离开、重复点击与异步保存交错。

**验证**：纯离开决策单测、组件与控制器接线测试、L0 + L2。临时本地或合成环境测试成功/失败；真实远端写入需独立授权。

**落地取舍（2026-11-24）**：`SettingsPanel` 注册只读状态与 `save/discard` 小接口，`Admin` 固定首个离开目的地，原生对话只表达三种选择。面板以提交时快照推进 baseline，布尔保存确认与实际新设置均吻合才认定成功；远端成功但本地应用失败仍返回失败。注册句柄只在回调/资格/会话真正改变时撤销，避免 props getter 随 value 更新重跑时误关确认框。会话引用从 App 传到面板，控制器 reset 作废保存代次；身份替换与失效分别清理，保持临时网络刷新和认证清理的边界。

合成 Chrome 的 8 组 / 24 项断言覆盖三选操作、保存成功/失败、返回首页与退出、真实刷新提示、会话失效和迟到保存，以及深色对话实际颜色。该测试运行实际构建，API 均被拦截，不代表生产保存或完整真机验收；原始 JSON 和截图留在仓库外。

### PROB-42：分类和来源文字的对比度

**原因与入口**：活动目录把装饰强调色直接用于小字号文字，部分纸页预设的声明颜色对比不足；聚合来源标签同时使用很小字号和透明度。当前自定义分类标题也有低对比组合。

**职责**：预设颜色由 `themePresets` / `themePresetRender` 负责；文字色与装饰色是不同职责。合成和对比计算属于 `src/lib` 的纯逻辑，展示组件消费结果；设置预览显示提示，不自行写持久化。

**实现范围**：必要的文字颜色变量、Sidebar/分类标题/来源标签、颜色预览提示与针对性测试。保留用户已有颜色值与默认空值跟随主题语义，不静默覆盖自定义颜色；不为纯视觉修复更改 API 或扩展历史 accent 功能。

**验收**：预设文字在实际背景上达到普通文字 4.5:1 目标；单纯声明卡片实底计算不能代表半透明混合；来源标签可读且不挤压卡片；自定义低对比有提示与可执行改法；浅/深、活动、悬停、焦点和强制颜色模式可用。

**验证**：纯颜色计算与预设一致测试、L0 + L2 预设矩阵、真实合成取样；审美验收和未覆盖背景组合分别说明。沿用 REQ-08b 的人工预设验收边界，不把局部计算升级为全部主题验收。

**落地取舍（2026-11-24）**：预设渲染增加独立的 `accentTextColor/darkAccentTextColor`，纸页文字使用既有安全标题色，装饰 accent 保持原值；毛玻璃沿用已有文字强调色。`buildHomeBackground` 输出文字变量，Sidebar 只替换文字用途，不把边框与背景混入同一规则。来源与目录计数使用既有描述色而不再叠加额外不透明度。颜色提示的 source-over 与 WCAG 计算仅随设置分包加载，纯色背景/遮罩可计算，空间背景和自定义 CSS 明确不可自动确认；提示关联输入，不覆盖已保存值。

合成 Chrome 的 46 组 / 186 项断言检查 22 个预设的明暗活动导航、来源文字、60px 卡片尺寸、自定义低对比/图片提示及强制色焦点。实际前景与隐藏字形后的同位置背景取样是局部估算，最低导航约 5.05:1、来源约 5.40:1；不将三点取样等同于全页或全部位置验收。前两轮测试问题修正为等待入场透明度稳定并提升合成数据版本，保留失败记录，产品实现及阈值没有因此改动。

### PROB-43：启动 SVG 减少动态效果

**原因与入口**：`app.css` 的 reduced-motion 选择器仍匹配旧 `span`，`AppSplash` 实际使用的 spinner、ring、dot 无限动画未被覆盖。

**职责与范围**：启动动效归 `AppSplash` 及所属样式，媒体偏好沿用既有管理；只调整实际节点的动效规则。适合取消的空间动效默认静态，在 `no-preference` 下启用；保留加载文案和状态，不依赖动画结束推进业务。

**验收**：reduce 下无原速旋转/描边/脉冲，普通模式正常；内容和最终状态不隐藏；不使用全局极短动画时长补丁。

**验证**：L0 + L2，浏览器模拟 reduce 并读取实际 SVG 动画，覆盖启动延迟/失败。局部 CSS 不为扫描字符串增加无行为价值的测试。

**落地取舍（2026-11-24）**：三条 SVG 动画声明移到同一 no-preference 媒体块，默认静态绘制保持尺寸、颜色与描边；旧 span 选择器移除，ring 自身没有 transform，只保留 spinner 与 dot 所需的变换原点。Chrome 在请求挂起的真实启动界面测得 reduce 三节点无活动动画，正常偏好各有一个；释放请求后两种状态均正常进入首页。首屏 CSS 最终 86,991 bytes，未提高预算；没有新增源码字符串测试充当动画行为证明。

### PROB-44：搜索引擎选择器键盘模型

**原因与入口**：`SearchBox` 的选择列表声明 listbox/option，只有 Escape 处理；原生 Tab/Enter 可用，但方向键和选择后回焦点不完整。

**职责**：`SearchBox` 继续拥有所选引擎和打开态，设置提供引擎列表/默认值。纯导航索引计算可独立测试；焦点副作用只在组件；不新建全局搜索状态。

**方案**：优先标准 select；保留图标列表时实现完整 listbox 焦点模型。可定制 select 外观能力须渐进增强，不因框架类型暂未支持就剥除语义。

**验收**：方向键打开和游走、Home/End、Enter、Escape、选中回焦点、失焦关闭、默认设置变化、触屏；预览不发外部搜索。

**验证**：L0 + L2，保留默认引擎同步与已覆盖关闭行为；不得称为完全没有键盘支持，也不同时改 REQ-19 的搜索意图。

**落地取舍（2026-11-24）**：保留现有图标列表，将已选引擎与活动焦点分开。`searchEnginePicker` 只计算方向键及 Home/End 的索引；`SearchBox` 单独拥有开关、单一选项 Tab 停靠点、实例级列表标识及焦点副作用。方向键从当前选项打开并循环，Enter/Space 使用原生按钮的点击行为提交，Escape 取消并返回入口，Tab 在原生焦点转移后关闭列表。配置、列表与预览变化会修复或关闭焦点；延迟聚焦用版本及当前焦点守卫，避免关闭后或快速重开的旧操作抢焦点。既有默认同步、手动选择、输入内容和外部提交契约继续保留。

### REQ-18：触屏完整阅读书签内容

**原因与入口**：信息卡单行省略，触屏隐藏 tooltip；长标题与说明缺少可发现的完整查看入口。

**职责**：卡片展示与局部详情交互归卡片组件；访问、编辑和排序仍通过既有回调编排。详情状态不复制书签持久化，也不修改图标调度和网络行为。

**实现范围**：保留单击访问主行为，提供明确详情入口或在允许高度内两行说明。根据组件自身宽度调整时使用 container queries，尊重已有 card layout 与用户尺寸设置。避免在主链接内嵌另一个可交互控件。

**验收**：长中文标题、长域名、说明可完整阅读；键盘、触屏和桌面入口可发现；详情与长按编辑、右键、移动/排序不冲突；320/390px、缩放与两种卡片样式无布局破坏。

**验证**：局部交互/回调组件测试、L0 + L2 真实输入与尺寸检查；不引入未经要求的备用卡片实现。

**落地取舍（2026-11-24）**：`BookmarkCard` 拥有本地详情开关及资格，主链接旁的可见按钮使用节点原生监听隔离指针、触摸和点击，并取消长按计时；详情正文打开时不再启动卡片长按。排序、预览、书签身份变化及卸载清理详情。`BookmarkDetailsDialog` 只呈现已获准显示的完整标题、说明、网址和来源，使用 `showModal()`、原生关闭表单与 close 通知，不接入访问登记或图标请求。信息卡预留右侧空间；极简卡和自身宽度不超过 120px 的卡片将入口放在底部独立一行，保留用户 40px 宽度下限及主链接配置高度。触屏入口至少 40×40px，完整文字允许换行，关闭区随正文滚动保持可达。

固定标题栏的背景必须覆盖弹窗的 16px 内边距；与内边距匹配的负偏移和边距用于阻止滚动正文从标题上方露出，不应在整理样式时直接归零。

### REQ-19：收藏筛选与网页搜索的提示及结果通知

**原因与入口**：Home 用输入筛选收藏，SearchBox 提交则打开外部引擎；现有“搜索”标签不区分两种意图，HomeContentSummary 的结果计数没有异步通知。

**职责**：Home 继续拥有筛选词及防抖结果；SearchBox 只编排当前引擎外部提交；HomeContentSummary 展示稳定、简短的计数状态。通知不得复制索引或增加网络请求。

**实现范围**：清晰按钮/输入提示、当前引擎的可感知说明，以及稳定的 polite/status 计数区域。沿用防抖，不读整列表，不在每次输入重复播报。

**验收**：筛选与外部搜索意图可区分；清空/零结果/连续输入通知可控；Enter 与 IME 不误提交；预览、管理员快速新增网址、Spotlight 独立状态继续保持。

**验证**：组件与纯结果计数测试、L0 + L2；真实读屏体验另列。测试外部提交时拦截合成目标，不把用户查询发送到真实引擎。

### REQ-20：窄屏站点标题的换行与字号

**原因与入口**：`HomeHeroSearch` 使用配置固定像素字号与强制断行，320px 中出现单字/括号单独落行。
