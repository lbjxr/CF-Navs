## 第一项：可信图标支持项目自身生成的 SVG

### 原因

logoSurfIcon 输出带 charset=utf-8 的 data URI，而前后端新解码正则拒绝该参数，阻断 revision、物化和可信视图；标准模式仍能由浏览器直接显示。

### 边界与实现

- shared 的纯函数负责受限 data URI 语法、解码与字节上限；只支持既有无参数格式及可选 UTF-8 charset、末尾 base64 标记。未知字符集/参数拒绝，不静默按 UTF-8 误读。
- Worker 保持图片正文嗅探和内容哈希所有权；共享解析成功不等于图片可信。
- 前端保持 Blob 构造、哈希校验、浏览器实际解码和存储编排所有权；共享函数不依赖 UI、DOM、数据库或网络。
- 不改变协议版本、revision 算法、租约、会话边界、缓存键、容量上限和图片生成格式；前后端使用同一解析实现，避免再次漂移。

### 验收

- 项目实际 logoSurfIcon 输出通过解码；带/不带 UTF-8 参数的同一正文具有相同 revision。
- 非图片、无效编码、未知参数、超出单图体积继续拒绝。
- 真实 SQLite/D1 创建→会话鉴权副本接口→前端 loader 持久化路径通过；覆盖旧记录没有 revision 的按需修复。
- Chrome 隔离本地实例中，带 charset SVG 在可信模式显示为有效 Blob，随后重载/离线仍复用；标准模式不回归。造数仅限一次性本地数据库，不向共享测试站点写业务数据。
- 类型检查、完整单测、构建、真实 Chrome 图标回归、差异检查。

## 第二项：LRU 命中时间接入真实流程

### 原因

read 只累积内存 touches，flushTouches 无生产调用者，持久化 last_used 不能反映热点访问；文档承诺的流程层接线缺失。

### 边界与实现计划

- touches、合并落盘、事务和租约检查仍由 iconCopyStorage 所有；不要让组件遍历/修改 IndexedDB。
- 在容量淘汰决策之前合并当前有效命中记录，使本次决策可见最新访问顺序；处理流程需保证代际/作用域未改变。
- 由图标流程或设备生命周期安排有界批次 flush，在页面挂起/退出前尽力提交；不引入永久轮询，不把每次响应式渲染变成写事务。
- 失败不得产生未处理拒绝；失效租约不复活已清理数据。明确 flush 失败时如何保留或重试当前批次，避免清空 touches 后悄悄丢失记录。
- 跨标签各自批次只能单调提升 last_used；保持容量及元数据计数一致。

### 验收

- 真实 loader 命中→流程 flush→原生 IndexedDB last_used 更新，而非测试手动调用 flush 代替生产接线。
- 容量压力下，早写入但最近命中的条目晚于冷条目淘汰。
- 批次去重、并发读写、跨标签旧批次、注销/关闭信任清理、事务失败和组件销毁均不越过租约边界。
- 真实 Chrome 观察持久化时间变化与重新打开后的顺序；性能检查合并写次数有界，无新增轮询。
- 类型检查、完整单测、构建、原生存储回归及图标 UI 回归。

## 第二项实现边界细化

- objectIconLoader 的本地命中完成后，触发一个 1 秒合并窗口；窗口不因更多命中而无限后移，也不在空闲或失败后自循环。iconTouchFlush 只负责时机，存储仍由 iconCopyStorage 所有。
- 页面隐藏/pagehide 经 iconDevice.checkpoint 尽力提交；loader 销毁取消待执行定时器并提交待处理批次。关闭信任/注销后不重新开放写许可。
- 容量压力下，put 在同一个 IndexedDB 写事务里合入当前实例的 pending touches，再决定淘汰；不在正常命中路径扫描全表。
- touches 只在事务成功后按条目对象身份确认清除，期间到达的新命中保留；失败批次等待下次真实需求或生命周期事件，不添加无限重试。
- 每条命中携带租约与有效性谓词；事务末尾再次核对，旧 scope/generation、失效会话与关闭实例均不能更新。其他连接较旧的时间不能倒退持久化 last_used。
- 同代际 activate 不再清空待落盘命中；切换代际时才丢弃不匹配项。异步失败只报告给仍有效的原会话。
- 页面强制终止不保证最后一批可提交；其他标签尚未提交的命中在本标签的容量决策中不可见。这是有界合并写的边界，不承诺跨标签实时全局 LRU。

## 推送后发现的验证阻塞：小幅服务器时钟超前

- LRU 修复 cf3b92d 推送后，专项脚本多次停在首页图标等待，不能将新 bundle 出现当成通过。常规生产验收 30/30 仍通过，但未覆盖可信冷启动。
- 只读浏览器诊断确认：控制器 phase=checking、epoch=0、无 lease，数据集匹配且无 HTTP/页面异常，IndexedDB enabled 但 entries=0；认证回执 checked_at 比本机记录 observedAt 超前 589ms。
- 原因是既有 clock 拒绝分支被映射为 expired，再被“当前租约未过期”保护忽略，没有后续重检。不是把正常网络慢或接口故障当作回归。
- 补充修复：0～5000ms 的新回执超前且没有本机时间回退时，保持禁止读取，等待本机时钟追上后最多重检一次。保持回执时间、会话到期和 24 小时边界不变；大偏差/回退提示同步时钟并重新校验。撤销信任、更新回执或销毁时取消等待；时钟不前进也不无限轮询。
