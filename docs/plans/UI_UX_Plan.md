## 三、【外观与卡片 - 高级设置】模块

> 💡 **核心布局优化建议**：在高级设置内使用 `[ 浅色模式 | 深色模式 ]` 的内部 Tab 标签页切换，一套表单控件即可配置两套模式，表单高度立减 50%。

| 配置项名称 | 当前控件形态 | 文字说明处理策略 | 推荐文案 / 提示内容 | 控件形态与排版改造建议 |
| :--- | :--- | :--- | :--- | :--- |
| **背景类型** | 分段选择器 (纯色/渐变/图片) | **直接删除说明** | 无 | 选中“纯色/渐变”时，后方“背景值”输入框变为颜色选择器；选中“图片”时变为 URL 输入框。 |
| **背景值 + 图床上传** | 文本框 + 外链跳转按钮 | **内置化** | `placeholder="请输入图片 URL 或点击右侧上传"` | 将“打开图床上传 ↗”做成输入框的**内部后缀按钮 (Input Suffix Button)**，节省横向空间。 |
| **遮罩颜色** | 文本框 + 色块 | **转为 Tooltip (?)** | **Tooltip 内容**：`覆盖在背景图上的蒙层颜色，浅色模式推荐白/浅灰，深色推荐黑/深蓝。` | 与模糊度、透明度整合为一行栅格。 |
| **模糊度** | Slider 滑块 | **内置化** | `0 px`（滑到 0 时无需多余文字，右侧数值直观反映） | 移除下方“对图片应用模糊…”的文字。 |
| **遮罩透明度** | Slider 滑块 | **内置化** | 右侧显示百分比 `10%` | 移除下方“叠加在背景上…”的文字。 |
| **卡片最小宽度** | 纯数字输入框 | **内置化**（单位后缀 + 占位符） | 输入框右侧常驻单位 `px`，`placeholder="默认 80"` | 增加 Tooltip 说明：“控制一行能容纳的卡片数量，支持自适应换行”。 |
| **详情卡片最小高度** | 纯数字输入框 | **内置化** | 输入框右侧常驻单位 `px`，`placeholder="0 为自适应"` | 移除下方说明；当卡片风格选择“极简”时联动置灰。 |
| **极简卡片图标大小**| 纯数字输入框 | **内置化** | 输入框右侧常驻单位 `px`，`placeholder="默认 60"` | 仅在卡片风格选择“极简”时激活，详情风格下联动置灰。 |
| **卡片表面颜色** | 文本框 + 色块 | **转为 Tooltip (?)** | **Tooltip 内容**：`书签卡片的背景底色，配合不透明度实现毛玻璃质感。` | 与卡片透明度、文字颜色并排为 3 列标准栅格。 |
| **卡片不透明度** | Slider 滑块 | **内置化** | 右侧显示数值 `65%` | 移除下方“数值越低越通透”废话。 |
| **卡片文字颜色** | 文本框 + 色块 | **内置化** | `placeholder="留空跟随系统高对比色"` | 移除下方两行小字。 |
