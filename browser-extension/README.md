# CF-Navs 浏览器书签同步扩展

这是一个 Chrome / Edge Manifest V3 扩展。它监听浏览器中之后新增的网页书签，在当前页面右上方的悬窗中显示一级、二级分类，并在用户确认后将书签单向写入 CF-Navs 的所选分类。点击扩展图标可以展示或隐藏悬窗；切换标签页、网页跳转或点击悬窗外的网页区域都会收起悬窗。分类确认前可以修改书签标题和 URL。扩展面板使用 CF-Navs 项目图标和卡片式连接界面；密码只用于登录，扩展保存会话令牌、最近使用的分类、浏览器书签标识和待同步收藏，并在当前浏览器会话中保存弹窗草稿。

`icon.png` 与项目 `public/icon.png` 同源；由于浏览器加载的是独立扩展目录，扩展包必须保留这份自包含副本，用于 16/32/48/128 像素的显示配置。

## 使用方式

1. 先在 CF-Navs 管理后台的“设置 → 站点设置”开启“浏览器书签同步”，并创建需要使用的分类。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择本目录。
3. 点击扩展图标，首次使用时填写导航页地址、管理员账号和密码，点击“登录并开启同步”。连接成功后首页只显示连接摘要，地址、账号和密码输入框默认收起；点击“修改登录信息”即可展开并更新。密码只用于登录，不会保存；扩展只保存会话令牌。
4. 以后新增网页书签时会在当前页面右上方显示分类悬窗。可以先修改标题和 URL，再选择分类并点击“确认同步”；不会自动修改分类，也不会同步浏览器收藏夹文件夹结构。
5. 点击扩展图标或首页的“处理待同步收藏”会打开待同步列表。列表默认不勾选记录，顶部显示已选数量；按需勾选或点击“全选”后，再同步或删除选中项，未勾选的记录会保留。
6. 列表每次打开或点击“刷新状态”都会读取浏览器收藏。刷新保留当前选择，新增记录与删除后剩余的未选记录不会自动勾选；刷新失败时保留已有列表和选择。已经不在浏览器收藏中的记录会以红色标记并保留，确认后可以手动删除；手动删除的待同步记录下次不会再次出现。
7. 点击“同步选中”后，扩展会逐条要求选择目标分类；点击“稍后处理”会返回扩展首页，不会上传或丢弃记录。
8. 服务端会校验目标分类仍存在。分类已删除或请求失败时记录保留在待同步队列，不会静默写入其他分类。

## 弹窗恢复

- 切换标签页或点击外部只隐藏弹窗，返回原标签页不会自动弹出；点击插件图标才会重新显示。
- 所有标签页共用最近一次打开的扩展页面。新增收藏打开同步确认后，即使另一个标签页之前停留在待同步列表，再点击图标也会进入最新的同步确认页。
- 隐藏、换标签页或刷新普通网页后，待同步勾选、同步标题、URL 和分类选择会恢复。重新读取队列、分类或连接状态时保留已有编辑；已经被处理的记录不会再次提交。
- 同步请求进行中切换标签页，新弹窗会显示正在同步并等待原请求结果，不会自动重复提交。只同步勾选的批次，完成后未选的收藏仍留在待同步列表。
- “返回首页”和“稍后处理”会明确进入扩展首页；关闭弹窗不会触发这类页面切换。
- 草稿存于扩展的 `storage.session`，仅在当前浏览器会话内有效；浏览器退出、禁用或重新加载扩展会清除草稿，已保存的待同步队列仍保留。密码不写入草稿，跨标签或刷新网页后需重新填写。

悬窗只会注入普通 `http` / `https` 网页；浏览器内置页面（例如 `chrome://extensions`）禁止扩展注入内容，需切换到普通网页后再点击扩展图标。

关闭后台开关后，服务端会拒绝同步请求；扩展也可以单独暂停同步。暂停同步不会清除待同步收藏。整个功能没有删除接口，不会删除或反向覆盖导航页已有书签。旧客户端省略 `category_id` 时，服务端仍按兼容行为写入“浏览器新增收藏”分类。

## 更新已安装的扩展

1. 更新原先加载的扩展目录中的文件。
2. 在 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions` 中，找到本扩展并点击“重新加载”。
3. 刷新已经打开的普通网页，使新版内容脚本在网页及其内嵌页面中生效。

仅更新导航站点不会更新本机扩展。重新加载扩展前，请先处理当前面板中尚未提交的编辑；重新加载扩展会清除会话草稿，已保存的待同步记录仍会保留。日常刷新普通网页可恢复本次浏览器会话中的草稿。
