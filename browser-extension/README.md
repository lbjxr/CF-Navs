# CF-Navs 浏览器书签同步扩展

这是一个 Chrome / Edge Manifest V3 扩展。它只监听浏览器中之后新增的网页书签，并将书签单向写入 CF-Navs 的“浏览器新增收藏”分类；同时支持把新标签页跳转到自定义网站，以及在访问 CF-Navs 书签时优先使用可达的内网地址。扩展弹窗使用 CF-Navs 项目图标和卡片式连接界面；密码只用于登录，扩展仅保存会话令牌。

`icon.png` 与项目 `public/icon.png` 同源；由于浏览器加载的是独立扩展目录，扩展包必须保留这份自包含副本，用于 16/32/48/128 像素的显示配置。

## 使用方式

1. 先在 CF-Navs 管理后台的“设置 → 站点设置”开启“浏览器书签同步”。开启时会自动创建“浏览器新增收藏”分类。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择本目录。
3. 点击扩展图标，填写导航页地址、管理员账号和密码，点击“登录并开启同步”。密码只用于登录，不会保存；扩展只保存会话令牌。
4. 以后新增的网页书签会自动进入“浏览器新增收藏”。文件夹结构不会同步，也不会自动改动现有分类。
5. 需要整理时，在导航页开启排序，直接把书签拖到目标分类。
6. 在扩展弹窗的“自定义新标签页”区域填写你自己的网址并开启跳转。扩展不内置任何个人域名，首次使用必须自行填写。关闭开关时，扩展不会跳转，但由于 Chrome 的扩展机制限制，仍会显示本地提示页；要完全恢复 Chrome 默认新标签页，需要在 `chrome://extensions` 中停用 CF-Navs 扩展。

## 内网地址优先访问

1. 在 CF-Navs 后台编辑书签时，外网地址填写常规公开入口；“内网地址（可选）”填写同一服务的局域网入口，例如 `http://192.168.1.100:8080/`。
2. 安装本扩展后，打开 CF-Navs 页面点击该书签，扩展会在本机短暂探测内网地址；能连通就打开内网地址，不能连通则自动回退到外网地址。
3. 没有安装扩展，或书签没有填写内网地址时，仍按原来的外网地址打开。扩展源码和安装包不内置任何个人域名。
4. 新版 Chrome 可能在首次访问局域网地址时显示本地网络访问权限提示，需要允许扩展访问本地网络。

关闭后台开关后，服务端会拒绝同步请求；扩展也可以单独暂停同步。整个功能没有删除接口，不会删除或反向覆盖导航页已有书签。

## 版本与出处

- **普通版**：只保留浏览器书签单向同步功能。
- **极客版**：包含浏览器书签同步和自定义新标签页功能。
